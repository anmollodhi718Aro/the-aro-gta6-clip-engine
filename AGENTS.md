# THE ARO Repository Instructions

**Mandatory first read for every AI coding agent and contributor.**

Before any coding or repository action:
1. Read `docs/ARO_AI_CODING_POLICY.md` and follow it strictly.
2. Read `docs/ARO_CHAT_STARTUP_PROMPT.md`.
3. Read the latest entries in `docs/CHAT_WORKSTREAM_REGISTRY.md`.
4. Verify current branch, HEAD SHA, open PR state, changed files, and CI evidence.
5. Continue the latest pending task without duplicating prior work.

The policy governs all AI-assisted work in this repository, including planning, coding, tests, reviews, commits, PRs, media handling, and publication. Owner approval is required for protected actions listed in the policy. A `continue coding` instruction authorizes safe in-scope engineering work only; it does not authorize merge, deployment, public upload, publication, or bypassing media-rights gates.

Canonical policy: [docs/ARO_AI_CODING_POLICY.md](docs/ARO_AI_CODING_POLICY.md)

If a platform does not automatically load `AGENTS.md`, the owner must provide these instructions to that agent at session start. Repository files cannot technically enforce behavior in an external AI service that ignores them.
