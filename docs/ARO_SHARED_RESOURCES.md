## Owner approval

The owner has approved this repository to discover, read, evaluate, and use the resources in the central catalogue where they are relevant to this project's goals.

This approval is **not** a blanket grant of private repository data to external websites, MCP servers, plugins, or third-party agents. Use only existing authorized connections and least-privilege permissions. Never disclose secrets, tokens, private source, or personal data to an external service without separate, explicit approval of that exact integration.

## Adoption rules

- Follow this repository's own master instructions, security policy, tests, and workflow gates first.
- Verify each resource's current source, licence, maintenance, compatibility, and cost before use.
- Do not auto-install tools, skills, packages, MCP servers, or remote scripts. Propose and review exact changes in an isolated branch.
- Do not push directly to `main`, merge, deploy, or publish without the required owner approval.
- Keep resource adoption scoped to this repository's needs; do not copy unrelated workflows.
- GTA VI Clip Engine work remains governed by its P0 priority and existing safety/approval gates. This reference file does not authorize bypassing them.

This file is a pointer and local adoption policy. It does not claim that any integration has been installed or that any external service has been granted repository access.
